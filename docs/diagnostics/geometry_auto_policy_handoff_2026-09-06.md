## Classification and preserved contracts

This is a scientific/versioned policy addition, not cleanup. It preserves all
existing candidate, comparison-v1, reviewed-candidate, selection, gate, digest,
recipe-default, and human-review behavior. Historical stored comparisons are
not rewritten. Old serialization continues through its existing owner; the
new closed shadow schemas explicitly use the existing shared canonical-JSON
manifest serializer, with golden digest tests.

The new `operationally_corroborated_acquisition_shadow_v1` policy cannot be
enabled. Its only mode is `shadow`; every result declares no selection, no
scientific acceptance, no promotion, and no acquisition-gate modification.
The output is a numerical policy evaluation, **not** a new acceptance receipt.
The shared acceptance design remains the owner of any future use-scoped
acceptance/activation work.

Physical feature labels remain independent from numerical agreement. The
review-free adapter always records `projected_edges_unresolved` and omits
same-feature radius-error metrics. It does not claim the top edge and inner
water-side edge are the same physical boundary. Confirmed different features
remain review-required in the evaluator. The acquisition gate is copied
unchanged, with inclusive boundary and zero additional Palette tolerance.
The independent-fit representative is validated by the metrics owner's actual
observed-window medoid rule, never manufactured by averaging rim radii.

## Narrow public interfaces

`shared.arena_geometry_auto_policy` owns:

- `build_geometry_auto_policy(thresholds=None, calibration=None)`;
- `validate_geometry_auto_policy(policy)`;
- `validate_geometry_shadow_evidence(evidence)`;
- `evaluate_geometry_auto_policy(policy=..., evidence=...)`.

All 18 limits must be supplied together with frozen derivation evidence before
any threshold-pass classification is possible. There are no numerical enabled
defaults. The limits cover center/IoU agreement, actual total and directional
detection-row disagreement, nonempty row coverage, angular/visible/quadrant
image support, unsupported arc and radial residual, temporal center/radius
variation, rim-family center spread/radial Hausdorff variation/candidate
coverage, and frozen acquisition-boundary support/radial offset.

Calibration references bind the derivation manifest/result, freeze timestamp,
optional paired validation manifest/result, exact scientific-recipe digest,
and rig/canvas/arena/camera/coordinate-profile/native-dimension applicability. They are
evidence references, not proof of holdout acceptance or policy promotion.
Changing any threshold changes the policy digest. Changing the applicable
scientific recipe, canvas, arena, or camera context blocks threshold reuse.
The canonical acquisition candidate does not supply a dish-design identifier;
this policy does not invent one. Any later policy that generalizes across
physical dish designs needs a separately reconciled applicability contract.

`arena_geometry_comparison.build_arena_geometry_shadow_evaluation(...)` reads
an existing acquisition candidate, an immutable unreviewed fit package, and an
exact active canonical detection rowset. It validates fit artifacts before
metrics, then checks blind-fit declarations, live source/coordinate identity,
image-support observation/circle identity, and finite nonempty detection rows.
It does not require or construct a manually reviewed Palette candidate.
It returns numerical evidence, actual gate-disagreement counts, and the shadow
evaluation without mutating the archive.

The equivalent read-only command is:

```bash
scripts/py -m fisheye.utils.evaluate_arena_geometry_shadow RECORDING.zarr \
  --acquisition-candidate-run EXACT_ACQUISITION_CANDIDATE \
  --fit-review-run EXACT_METRIC_BEARING_FIT_RUN \
  --detect-source-group detect_runs/EXACT_CANONICAL_RUN
```

`--policy-json` optionally supplies an exact frozen shadow policy. There is no
`--apply` flag. Without it the result explicitly reports uncalibrated/inactive
thresholds; missing or invalid metric-bearing evidence is a refusal, not an
acquisition-only fallback.
